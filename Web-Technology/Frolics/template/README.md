# Frolics Theme Template (Static Reference)

This folder contains a portable, single-page reference of the Frolics landing UI for sharing with others or using as a starting point outside the main app.

## Files
- `index.html` — static page with hero, nav, stats, and feature grid.
- `styles.css` — self-contained styling (colors, gradients, glassmorphism, responsive tweaks).

## How to preview
1. Open `index.html` directly in a browser (no build step required).
2. Icons use Feather via CDN; the page works offline minus icons (they gracefully fall back to text).

## How to reuse
- Copy both files into any static host or framework and adjust links/actions.
- Replace logo text with your own brand; update gradients in `:root` to match your palette.
